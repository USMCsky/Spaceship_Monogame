# Spaceship_Monogame

A simple MonoGame project featuring a spaceship dodging asteroids.

## Overview

This repository contains a compact 2D game prototype built to explore core MonoGame concepts, including the game loop, input handling, and sprite-based movement.

## Tech Stack

- C#
- MonoGame

## Getting Started

### Prerequisites

- .NET SDK (latest stable)
- MonoGame framework/tools
- Visual Studio, Rider, or another C# IDE

### Run the Project

1. Clone this repository.
2. Open the solution in your IDE.
3. Restore NuGet packages.
4. Build and run.

## Project Structure

- `Spaceship_Monogame/` — game source code and assets
